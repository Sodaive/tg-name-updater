# Telegram Profile Time Updater

اسم پروفایل تلگرام شما را به‌صورت خودکار و زنده با ساعت فعلی (به وقت تهران) به‌روزرسانی می‌کند.

## ویژگی‌ها
- به‌روزرسانی خودکار نام پروفایل با ساعت لحظه‌ای
- اجرا کاملاً روی GitHub Actions — نیازی به سرور شخصی نیست
- رایگان و بدون محدودیت (با ریپوی Public)

## پیش‌نیازها
- یک اکانت تلگرام
- یک اکانت GitHub
- Node.js (فقط برای مرحله‌ی اولیه‌ی لاگین)

## نصب و راه‌اندازی

### ۱. گرفتن API credentials
از [my.telegram.org](https://my.telegram.org) وارد شوید و `api_id` و `api_hash` را از بخش API development tools بردارید.

### ۲. Fork کردن این ریپو
روی دکمه‌ی Fork بالای صفحه کلیک کنید.

### ۳. گرفتن Session String
مخزن را کلون کنید (یا از GitHub Codespaces استفاده کنید) و دستورات زیر را اجرا کنید:
```bash
npm install telegram input
node login.js
```
(فایل `login.js` را طبق نمونه بسازید — این فایل هیچ‌وقت نباید commit شود.)

### ۴. تنظیم GitHub Secrets
در ریپوی fork‌شده‌ی خودتان، به Settings → Secrets and variables → Actions بروید و این مقادیر را اضافه کنید:
- `TG_API_ID`
- `TG_API_HASH`
- `TG_SESSION`
- `TG_BASE_NAME` (اسمی که می‌خواهید قبل از ساعت نمایش داده شود)

### ۵. فعال‌سازی Workflow
از تب Actions، ورک‌فلو را یک‌بار به‌صورت دستی اجرا کنید (Run workflow).

## به‌روزرسانی هر ۱ دقیقه (اختیاری)
به‌طور پیش‌فرض هر ۵ دقیقه اجرا می‌شود. برای به‌روزرسانی هر ۱ دقیقه، از یک سرویس رایگان مثل [cron-job.org](https://cron-job.org) برای صدا زدن GitHub API استفاده کنید (جزئیات در Wiki).

## ⚠️ هشدارها
- **این پروژه از User API (نه Bot API) استفاده می‌کند** — یعنی با اکانت شخصی شما کار می‌کند، نه یک بات جدا.
- `TG_SESSION` معادل رمز کامل اکانت تلگرام شماست — هرگز آن را جایی به اشتراک نگذارید.
- استفاده‌ی زیاد ممکن است باعث محدودیت موقت (`FloodWait`) از طرف تلگرام شود.
- این روش نوعی خودکارسازی اکانت شخصی است؛ مسئولیت استفاده بر عهده‌ی کاربر است.
